Backend for **Silent Voice**, a real-time Indian Sign Language ↔ English
translator (FastAPI + MediaPipe + PyTorch BiLSTM / 1D CNN).

The website itself is served from GitHub Pages and calls this Space for
recognition, reverse translation, practice scoring and accounts.
